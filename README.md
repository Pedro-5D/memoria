# Memoria planetaria

Juego estático de un solo archivo (index.html) con los discos planeta-color de Izarren. Cinco modos: fácil 4×4, medio 4×6, difícil 4×8 y, en 4×4, emparejar por planeta o por color. Sin cookies ni rastreo; las partidas se guardan solo en el dispositivo.

Parámetros de URL: `?dia=1` (reto del día: las mismas cartas en el mismo sitio para todos), `modo=facil|medio|dificil|planeta|color`, `embed=1`.
