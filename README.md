# Memoria planetaria

Juego estático de un solo archivo (index.html) con los discos planeta-color de Izarren. Cuatro modos con los doce discos: fácil 4×3, medio 4×4, difícil 4×6 y por planeta (emparejar cada planeta con su otro color). Sin cookies ni rastreo; las partidas se guardan solo en el dispositivo.

Parámetros de URL: `?dia=1` (reto del día: las mismas cartas en el mismo sitio para todos), `modo=facil|medio|dificil|planeta`, `embed=1`.
